# Ali Kaabi, personal site

A single-page site for GitHub Pages. Everything is in `index.html` and `assets/`.

## Publish on GitHub Pages
1. Create a public repository named `kaabia79.github.io` (so the site lives at https://kaabia79.github.io), or use any repository and enable Pages.
2. Upload `index.html`, `README.md` and the `assets` folder.
3. Settings, Pages, Source: Deploy from a branch, Branch: main, folder: / (root). Save.
4. The site is live within a minute or two. For a custom domain (for example alikaabi.com.au), add a `CNAME` file containing the domain and point the domain's DNS at GitHub Pages.

## Live address
https://kaabia79.github.io (lowercase). Link straight to a tab with a hash: https://kaabia79.github.io/#projects or /#governance.

## Update it
- Text: edit `index.html`. Each section is marked with an id (`#method`, `#record`, `#cases`, `#recognition`, `#credentials`, `#contact`).
- Images: replace files in `assets/` and keep the same file names, or add new ones and reference them.
- CV: replace `assets/Ali_Kaabi_CV.pdf`.
